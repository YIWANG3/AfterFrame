New files: SettingsOverlay.jsx (4 tabs), AnnotationsSection.jsx (Description / Tags / Location in inspector), AnnotateConfirmDialog.jsx, electron/ipc/annotation.js, electron/ipc/settings.js (persist general settings to settings.json), sidecar adapter for each provider.

Tag reuse pipeline (silent, no UI): before each request, inject the top-200 most-used tags into the prompt; after the response, fuzzy-merge near-duplicates against the existing tag set before insert. User never sees a "reused" indicator — it just works.

Migration: existing AI Repaint provider config (currently configured inline in the editor panel) moves to Settings → AI → "AI Repaint" group. The editor panel keeps a small "Open in Settings" link.
