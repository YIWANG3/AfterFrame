# Brand logo census (2026-10-01)

Research for the built-in brand logos (`apps/desktop/frame-logos/`): for each brand on the whitelist, the EXIF strings that identify it, the best logo source, its licence, and the trademark risk. Gathered by a research workflow (Wikimedia Commons file metadata, Flickr EXIF pages, simple-icons, ExifTool / lensfun, makers' sites); nothing has been downloaded yet. Already built in: Canon, Nikon, Sony, Fujifilm, Leica, Lumix, Ricoh, Hasselblad, DJI, Insta360.

Licences: simple-icons is CC0; Commons PD-textlogo / PD-simple means the logo is below the threshold of originality (no copyright), but it is still a trademark. Almost every maker's terms forbid using its logo without written consent; showing the maker of the camera that took the photo is descriptive use, and the folder stays removable (see frame-logos/TRADEMARKS.md).

## Matching notes

- The built-in `fuji` needle also matches `FUJITSU` (arrows phones): match `fuji` only as the whole Make, or put `fujitsu` / `fcnt` first.
- `sigma` also matches the rugged phone maker `SIGMA_MOBILE`: match the whole Make `SIGMA`.
- `pentax` also matches the 2013 Ricoh GR, whose early firmware writes Make `PENTAX RICOH IMAGING`, Model `GR`: check the Model.
- `iqoo` before `vivo` (some iQOO phones write Make `vivo`, Model `iQOO 12`); older Honor phones write Make `HUAWEI` with Honor model codes.
- Co-branded phones go by their maker: Hasselblad OPPO / OnePlus, Leica Xiaomi, ZEISS vivo all write the phone maker as Make.
