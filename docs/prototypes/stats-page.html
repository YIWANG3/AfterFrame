概览

器材

真正在用的是哪几台、哪几支

相机需加工

占比 · 留用率 · 使用时间线
数据：meta_camera_model（已有索引列，FilterBar 的「相机」筛选也用它）。需加工：EXIF 里的机型是 ILCE-7CM2、RICOH GR IIIx 这种，要一张显示名映射表（Sony A7C II），不需要重新扫描。留用率 = P 旗标 /（P + X），衡量「这台机器出片率」。时间线 = 近 24 个月每月张数。超过 6 个月没用标「闲置」——卖器材前看一眼。

镜头需加工

按张数

常用组合现有字段

机身 + 镜头
数据：meta_lens_model。镜头名同样要归一（XF33mmF1.4 R LM WR 等）；固定镜头相机（GR、X100、手机）常常没有镜头名，按机型补成「内置」。注意：只通过「添加 RAW 来源」登记的 RAW 导入时只读了拍摄时间和机型，镜头 / 光圈 / ISO 要等「运行元数据补全」；普通导入的照片是完整读取的。

题材

拍什么，以及拍不同题材时用什么

题材分布需新扫描

已识别 46,870 / 48,213 张 · 本机识别，不上传
街拍和人像占了 53%；风光虽然只有 12%，留用率却最高。

每类题材怎么拍需新扫描

留用率 · 最常用镜头 · 中位焦段

题材 × 镜头需新扫描

每一行 = 这类题材里各镜头的占比
人像 71% 用 85mm 和 56mm；街拍几乎都是 GR 和 33mm。
现在没有题材数据。catalog 里能沾边的只有：用户标签（asset_tags，自由文本、覆盖率低）、AI 标注（asset_ai_annotations，要用户配 API 逐张跑，有成本）、人脸（只能推出「有人」）。要做题材，需要一个新的本机分类步骤：
· Mac：Apple Vision 的 VNClassifyImageRequest（系统自带、约 1,300 个标签、无需下载模型），在已有的 512 px 预览上跑，和相似照片任务（visual job，导入后自动补跑）同一遍读图，新增一张 asset_scenes 表存 top 标签，再由一张映射表归到 ~12 个摄影题材。
· Windows：暂无系统分类器，要带一个 CLIP 类 ONNX 模型做零样本分类（体积在 ≤1 GB 的约束内），可以后做；Windows 上先显示「仅 Mac」。
· 已有 AI 标注或用户标签的照片，优先用它们。

焦段（35mm 等效）需加工

定焦尖峰 vs 变焦分布
41% 落在 35–40mm。24-70 的 62% 停在两端（24 / 70），中间焦段很少用。
现在只存了物理焦距 focal_length。等效焦距按机型的画幅系数换算（APS-C ×1.5、M43 ×2、手机按机型），一张映射表、不用重新扫描；查不到系数的机型显示物理焦距。以后的导入可以顺手存 ExifTool 的 FocalLengthIn35mmFormat。
