# Prototypes & design archive

Static design explorations and throwaway prototypes kept for reference. None of
this is part of the shipping app or its build — it's history.

- `mockups/` — editor/sticker/annotation design iterations (HTML mockups)
- `batch-collage-ui.html`, `split-ui.html`, `people-arcface-ui.html` — the UI mocks linked from `batch-collage-plan.md`, `split-carousel-plan.md` and `people-recognition-design.md`
- `frame-watermark-ui.html`, `brand-layouts.html`, `hasselblad-layouts.html` — frame / EXIF watermark layout explorations (`assets/hb-sample.jpg` is their sample photo)
- `collage-templates-preview.html` — collage template preview
- `lut/` — LUT research scripts and the macOS Core Image RAW→LUT prototype behind `docs/lut-plan.md`

Superseded iterations were removed on 2026-10-14 and are in git history: the
editor-all-tools mockups v1–v6 and the first editor-crop mockup, `mock-ui/` (an
early product-direction comparison), `early-design/` (the Eagle-style SVG
mockups) and `lightbox-lab/` (a standalone Vite lightbox experiment).
