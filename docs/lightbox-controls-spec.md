# 大图预览控件固定

在大图预览中，用顶部工具栏的「固定」按钮统一控制顶部工具栏和底部栏。底部栏包括现有缩放控件和缩略图条。

「固定」是标题栏「详情」和「关闭」之间的纯图标按钮，宽高均为 36 px。图钉使用项目现有 `lucide-react` 图标库中的 `Pin`。按钮采用设计系统的图标按钮样式，默认透明，悬停时亮起图标和底色，固定时保持高亮。悬停提示根据状态显示「固定上下栏」或「取消固定上下栏」。

## 布局与交互

- **固定开启**：上下栏常驻，照片在现有图片区内等比适配。打开右侧详情时，沿用现有布局，为详情面板留出宽度。
- **固定关闭**：上下栏默认隐藏，照片以当前窗口内容区为边界，居中、等比完整显示。指针进入顶部工具栏、底部缩放和缩略图条或可用翻页箭头所在区域时，控件和玻璃背景一起淡入。指针留在控件区域内时，浮层保持可操作。指针移回画面中部后，浮层短暂停留再淡出。指针离开窗口时，浮层随即开始淡出。方向键在浮层显示和隐藏时都能翻页。
- **记住固定状态**：首次使用时默认关闭固定。切换后在本机记住选择，重新打开大图预览或重启应用时恢复上次状态。
- **默认缩放**：切换固定状态时，按新布局的图片区宽高同步重算适配比例。照片处于适配状态时，在新区域内等比居中。手动放大后，当前缩放仍大于或等于新适配比例时保留视图，低于新适配比例时回到适配。
- **右侧详情**：取消固定后，仍可用现有「详情」按钮打开或关闭右侧面板。面板覆盖在照片上，打开后可独立查看和操作。上下栏浮出时，详情按钮和「固定」按钮仍可点击。

## 改动范围

复用现有工具栏、缩放控件、缩略图条、翻页箭头和详情面板。改动集中在大图预览的「固定」按钮及其偏好、控件显隐、图片区边界和详情面板的摆放。照片适配当前窗口内容区，应用窗口的全屏状态由现有菜单独立控制。

图钉用于照片预览。校样模式和视频预览各自使用原有布局。

## 验收条件

- 标题栏「详情」和「关闭」之间显示图钉，点击后切换上下栏的固定状态。
- 首次打开大图预览时，固定处于关闭状态，照片按窗口内容区适配。
- 切换固定状态后，关闭再打开大图预览，或重启应用再打开大图预览，均恢复上次选择。
- 固定开启时，上下栏常驻。打开详情后，照片按扣除详情面板后的区域适配。
- 固定关闭时，指针从画面中部直接进入上下栏或可用翻页箭头所在区域，均可触发整组控件和玻璃背景淡入。指针离开控件区域后，整组浮层一起淡出。收起后仍可通过方向键翻页。
- 固定关闭时，上下栏显隐及右侧详情开关均不改变照片的缩放比例和位置。
- 在普通窗口和应用全屏下，相片处于适配状态时，切换固定会同步更新当前照片的大小、居中位置和缩放读数。
