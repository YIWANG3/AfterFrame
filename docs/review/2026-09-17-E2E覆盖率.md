# E2E 覆盖率：首次度量（2026-09-17）

> **状态（2026-09-17）**：工具已落地（`npm run e2e:coverage`，nightly 上传报告）。本文记录首次全量的数字、冷点和建议补的 spec；数字会过期，工具不会。

## 怎么跑

```bash
cd apps/desktop && npm run e2e:coverage            # 全量：插桩构建 → 171 条 e2e → 三份报告
cd apps/desktop && npm run e2e:coverage -- e2e/19-editor-layers.spec.js   # 只跑几个 spec
cd apps/desktop && npm run e2e:coverage:report     # 不重跑，只从已有数据重出报告
open apps/desktop/.coverage/report/renderer/index.html
```

三层各自采集，一份脚本（`apps/desktop/scripts/e2e-coverage.mjs`）合出报告：

| 层 | 采集 | 报告 |
|---|---|---|
| renderer `src/**` | `vite-plugin-istanbul` 插桩构建（仅 `AFTERFRAME_COVERAGE=1` 时），`closeApp` 前从每个窗口读 `window.__coverage__` | nyc |
| main `electron/**` | Playwright 启动时给主进程 `NODE_V8_COVERAGE`，退出时写 V8 数据 | c8（`--all`，未加载的文件按 0 计） |
| sidecar `media_workspace` | `transport.js` 在 `AFTERFRAME_SIDECAR_COVERAGE` 下把 dev sidecar 包成 `coverage run --parallel-mode`（resident serve + 每个 detached job runner 各一份，rcfile 开 `sigterm` 让 SIGTERM 也落盘） | coverage combine + html |

**没度量的**：`electron/preload.js`（跑在 renderer 隔离世界，V8 采集看不到，已从 main 分母剔除）、Swift helpers、web 版构建。renderer 只统计 Vite 实际打包进去的模块，从未被 import 的文件不在分母里（它们本来就是死代码）。

跑一次 4.6 分钟（未插桩全量 3.8 分钟），171/171 通过，插桩没改变任何 spec 的结果。

## 度量本身的注意事项

- 数字是 **e2e 独占**的，单测覆盖没合进来（`jobArgv.js` 单测覆盖 100% 但 e2e 只有 56%）。要合并需要 vitest / `node --test` 也出 istanbul 数据，另开一项。
- `--all` 让 main 和 sidecar 把没加载的文件按 0 计；renderer 做不到（istanbul 只插桩打包进去的），所以三个分母口径略有差别，各层纵向比较自己的变化就好。
- 跑完脚本会重新构建一份未插桩的 `dist/`，`npm run e2e:only` 不会误跑插桩包。
