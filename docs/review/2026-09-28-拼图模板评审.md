# 拼图模板评审（2026-09-28）

范围：`apps/desktop/src/components/collage/collageTemplates.js`（1 到 12 张，共 59 个模板），画布比例预设 1:1 / 3:4 / 4:3 / 2:3 / 3:2 / 16:9 / 9:16 / Full 加自定义。审计方式：脚本比对每个模板的 cell 集合（重复）、面积和（覆盖）、两两相交（重叠）。

## 结论

> 2026-09-28 已实施：20 个新增、2 个重复删除全部落地在 `collageTemplates.js`（生成器 `grid` / `sandwich` / `centre`），审计脚本落成 `collageTemplates.test.js`（每个模板一条用例：数量、覆盖、无重叠；全表无重复）。

现有模板够用，但几乎全是"等分网格 + 一边大一边小"，7 张以上明显稀，而且缺三类最常用的构图：

1. 主图占 2×2 的网格（Instagram / 小红书最常见的拼法）：4、6、8、9、12 张都没有。
2. 中间一张主图，两侧各堆 N 张：3、5、7 张都没有。
3. 上 N 张 + 中间一条横幅 + 下 N 张（用户点名：5 = 2+1+2，7 = 3+1+3）：只有 9 张的 4+1+4。

建议新增 20 个、删除 2 个完全重复的，净 77 个。定义见下文，可直接贴进模板表。

- [x] **F3 CONFIRMED** 没有"主图占 2×2"家族，见结论第 1 条。
- [x] **F4 CONFIRMED** 没有"中间主图"和"上 N + 横幅 + 下 N"家族，见结论第 2、3 条。
- [x] **F5 PLAUSIBLE** 模板表全部手写分数，重复项就是这么来的。建议加三个小生成器 `grid()` / `sandwich()` / `centre()`（下文代码里有），现有 id 不动；再把本次审计落成 `collageTemplates.test.js`（无重复、面积和为 1、无重叠、cell 数等于张数）。

  const out = [];
  for (let r = 0; r < rows; r++) for (let c = 0; c < cols; c++) out.push({ x: x0 + (c * w) / cols, y: y0 + (r * h) / rows, w: w / cols, h: h / rows });

## 实施要点

- 新模板追加在各组末尾：默认模板是每组第一个（`CollageOverlay` 取 `templates[0]`），不会变。
- 缩略图网格每行 5 个（`TemplateGrid`），7 张会变成 8 个占两行，其余组最多 11 个，都在可接受范围。
- e2e：`45-collage-single` 只按名字点 2 张、3 张的现有模板；`25-collage-batch` 按 groupSize 取模板池。都不受影响。建议顺手加上 F5 说的单测。
- MCP：`get_editor_capabilities` 自动列出新 id，agent 端不用改。
