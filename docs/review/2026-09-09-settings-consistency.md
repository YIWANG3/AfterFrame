# 设置页一致性分析(2026-09-09,Tahoe 皮肤,浅色主题截图 7 张)

范围:通用 / AI 标注 / AI 重绘 / 人物 / 图库 / 集成 / 关于。
依据:用户截图 + `src/components/settings/*.jsx`、`src/ui/fields.jsx`、`src/index.css` 第 10 / 10b 段。
结论先行:**结构是统一的**(都是 Group 卡 + FieldRow 行),问题集中在 **控件层**:同一语义有 2 到 3 种画法,浅色主题下 fill 叠 fill 导致对比不足,字号档位过多。

优先级:P0 = 影响可读 / 可用;P1 = 一眼能看出的不一致;P2 = 打磨。

## 1. 色彩与灰色块

- [x] **P0 · fill 叠 fill,控件陷在卡片里**。Group 卡底是 `--fill`(浅色 6% 黑),次要按钮 / 输入框 / 下拉底也是 `--fill`,同一灰叠同一灰,「在访达中显示」「打开…」「新建…」「移除」几乎和卡片融为一体(图库页最明显)。建议:卡片内的控件用 `--fill-2`,或者浅色主题下卡片内按钮用白底(Apple 浅色设置里的做法:灰组底 + 白控件)。
- [x] **P1 · 列表项两种画法**。AI 重绘的服务商行是白色卡片(`bg-app`,14px 圆角)叠在灰卡上;AI 标注的服务商行是灰底描边卡(选中时描边 accent);人物页的模型行没有卡,只有图标块。三处同一语义(「一个可选中的实例」)。建议统一为「灰卡内白色子卡,选中态 1.5px 内环」,和 AI 重绘现状一致。
- [x] **P1 · 残留发丝边**。「当前 Catalog」范围徽标(`border border-border/70`)、人物页的两个图标方块(`border`)、AI 标注选中行(`border-accent`)是页面里仅剩的描边,皮肤其他地方已全部去线。徽标改 `--fill-2` 实底;图标方块去边只留 fill。
- [x] **P2 · 提示块(Callout)风格独立**。人物页底部「你的照片不会离开这台 Mac」是左侧 2px 黑条 + 灰底,关于页的更新说明是普通灰卡。建议都用普通灰卡,不加色条。

## 2. 可读性 / 可辨识

- [x] **P0 · 开关关闭态轨道不可见**。`Toggle` 关闭态底色 `bg-hover`(浅色 236),落在 6% 灰卡上几乎同色,只剩一个白色圆点悬在半空(图库页「生成高清预览图」、人物页「自动下载更新」、AI 标注页「导入时自动标注」三处)。建议关闭态轨道用 `--fill-3`(15%)或 `rgb(var(--muted-text-2) / .35)`,并加 0.5px 内环;深色主题同样受益。
- [x] **P0 · 说明文字对比度不达标**。`text-muted2` 浅色主题是 158 灰落在 245 底上,对比约 2.3:1,11px 字号下低于 AA 的 4.5:1。所有 hint / subtitle / 路径都用它。建议浅色 `--muted-text-2` 压到 110 左右(对比约 4.6:1);深色的 122 在 17 底上约 4.6:1,可保留。
- [x] **P1 · 行内图标钮太小太淡**。刷新 / 编辑 / 删除是 12px 图标 + `text-muted2`,28px 热区;截图里几乎看不见。统一 14px 图标(和导航、关于页一致)+ `text-muted`,hover 才到 `text-text`。
- [x] **P1 · 标签语言 chip 选中态靠描边**。选中 = accent 描边 + 小圆点,未选中 = 灰底无边。改为选中 accent 实底(黑底白字)、未选中 `--fill-2`,与主按钮同一语言,去掉圆点。
- [x] **P2 · 「当前」/「LOCAL」徽标 8px**。中文在 8px 且带 0.1em 字距,发虚。徽标最小 10px,中文不加字距、不大写。

## 3. 圆角

现状一张页面里出现 8 档:覆盖层 18 / Group 卡 14 / 子卡 14 / 图标方块 10 / 按钮与输入 8 / 图标钮 8 / 徽标 2 / 胶囊。

- [x] **P1 · 子卡与父卡同为 14px,不同心**。AI 重绘 / AI 标注的服务商子卡 `rounded-lg` = 14,父卡也是 14,内缩 16px 后按同心公式应为约 8px。子卡改 8 或 10。
- [x] **P1 · 徽标 `rounded-sm`(2px)** 与全局 8px 体系脱节,改 4px 或胶囊。
- [x] **P2 · 图标方块 `rounded-md`(10px)在 36px 方块上偏大**,改 8px 与按钮一致。
- 建议收敛为 5 档:覆盖层 18 / 卡 14 / 子卡与控件 8 / 徽标 4 / 胶囊(chip、进度条、范围徽标)。

## 4. 字号

现状:关于页标题 18 / 覆盖层标题 14 / 组标题 12 / 行标签 12 / 下拉 12 / 数值框 12 / 按钮 11 / hint 11 / 副标题 11 / 模型下拉 11 / 次级说明 10 / 范围徽标 9 / 徽标 8。共 6 档在 8 到 12 之间。

- [x] **P1 · 收敛为 13 / 12 / 11 / 10 四档**:组标题 13 semibold(现在 12,和行标签同号,层级靠加粗撑);行标签 12;hint、副标题、路径、按钮、输入统一 11;徽标 10;不再出现 8 / 9。
- [x] **P1 · 同类控件字号不一**:`Select` 12、`NumberInput` 12、AI 重绘行内模型下拉 11、按钮 11。输入类统一 11 或统一 12,建议 12(输入更易读)、按钮 11。

## 5. 按钮色彩与层级

- [x] **P0 · 人物页三个黑色主按钮**。「下载 ArcFace R100」「选择模型…」「开始分析」全部 accent 实底,主次不分;Apple 规则是一组里最多一个主按钮。「选择模型…」改次要;「下载」与「开始分析」分属两组可各留一个。
- [x] **P1 · 「去某处」有三种画法**:关于页是文字链接 + 外链图标;集成页是只有外链图标;图库页是「在访达中显示」次要按钮。统一为「次要按钮 + 图标」或「文字链 + 图标」二选一,建议前者(命中区大)。
- [x] **P1 · 删除类动作两种画法**:监控目录的「移除」是文字次要钮,服务商 / 模型是垃圾桶图标钮。统一为图标钮,hover 变 error 色。
- [x] **P2 · 次要按钮文字色**:组件里是 `text-muted`,皮肤规则改成了正文色,以皮肤为准,组件类名可以顺手清理。

## 6. 其他

- [x] **P1 · 文案**:范围徽标写「当前 Catalog」,页面其余地方叫「图库」;统一为「当前图库」。
- [ ] **P2 · 人物页重复信息**:「人脸模型」卡和「已安装模型」卡各显示一次 ArcFace R100 · Core ML,第一张卡的模型行可以只留状态。
- [ ] **P2 · 关于页版本号**:截图里 tagline 下没有版本号,确认桌面版是否拿到了 `app.getVersion()`。
- [ ] **P2 · 行间距**:FieldRow `py-3`(12px)去掉分割线后靠留白分组,单行控件行显得挤,可提到 14px;子卡内间距保持 12。
- [x] **P2 · 覆盖层遮罩**:浅色主题也用黑色 45% 遮罩,和浅色底叠出偏脏的灰;浅色可用 `rgba(0,0,0,.25)` + 更强模糊。
