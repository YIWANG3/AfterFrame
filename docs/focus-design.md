# 焦点与键盘：鼠标点过的按钮不留焦点

> **状态（2026-11-26）**：规则已定，第 5 节的三个问题按建议拍板。第一步（规则 1 和 2）已实现：`apps/desktop/src/ui/pointerFocus.js`、`index.css` 开头的键盘焦点一节，e2e 在 `e2e/103-focus-rings.spec.js`。规则 3 到 5 还没做。

## 1. 问题

在编辑器里点一下工具栏的「边框」按钮，或者点一个边框模板，再按方向键，那个按钮上会出现一圈浅蓝色的双层框。这是 Chromium 默认的键盘焦点环（`:focus-visible`），App 自己没画。

原因是 Chromium（Electron 也是）在鼠标点按钮时会把焦点给这个按钮，而 macOS 原生控件、Safari、Firefox 都不会。焦点留在按钮上以后，只要按任意一个键，浏览器就认为用户改用键盘了，在这个按钮上画出焦点环。

这不只是样子的问题。焦点停在按钮上时，空格和回车会按下它。在 Electron 43.2.0 里用一个最小页面实测：

| 操作 | 结果 |
| --- | --- |
| 鼠标点按钮 A | A 拿到焦点，没有焦点环 |
| 按方向键 | A 出现焦点环 |
| 按空格（window 上的 keydown 没有拦） | A 被再点一次 |
| 鼠标点按钮 B，按空格（window 上的 keydown 拦了：`preventDefault`） | B 没有被再点 |

编辑器按住空格拖动画布时没有拦空格（`EditorOverlay.jsx` 的 keydown 只记一个 `spacePressed`），所以点完一个模板或开关再按住空格拖画布，松手时会把那个按钮再按一次。图库里执行了的快捷键都会 `preventDefault`，编辑器里的回车也拦了，所以这两处没有这个问题。

人物页已经被这个问题坑过：方向键换选中以后，要手动把焦点移到新卡片上，否则之前点过的那张卡片还留着焦点环，看起来两张都选中了。侧栏导航行和灯箱的固定按钮（#321）也各自在点击后手动 `blur()`。同一个需求打了三次补丁，一直没有统一的规则。

另外，留下的焦点会让 `:focus-within` 一直成立，靠悬停才出现的控件（灯箱的浮动控件等）在鼠标移开后也不收起来。#321 修的就是这个。

## 2. 一般 app 怎么做

- **macOS 原生 app**（访达、照片、Pixelmator Pro、Lightroom Classic）：点按钮不拿焦点。焦点环只出现在文本框上；用户在系统设置里打开「键盘导航」后，Tab 才会停在按钮上。
- **编辑类 app**（Figma、Pixelmator Pro）：点完工具栏，快捷键照样作用在画布上，跟刚才点了哪个按钮无关。
- **用主题色画焦点环**（VS Code 的 `focusBorder`）：焦点环换成自己的颜色，只在键盘操作时出现。
- **网格和列表**（Lightroom 的网格、照片、Linear）：方向键移动的是选中项，用选中样式表示，不画焦点环。

## 3. 改之前的情况（2026-11-26）

### 3.1 焦点样式

| 写法 | 位置 |
| --- | --- |
| 输入框聚焦时描边 `focus:border-accent/50` | 大多数输入框（Toolbar、LibraryToolbar、侧栏改名框、ManagerPages、NamePersonPopover 等） |
| 输入框内描边 `--fill-3` | `ui/fields.jsx`、工具栏搜索框 |
| 输入框换底色加描边 | 拼图的比例输入框 `.collage-ratio-input` |
| `outline-2 outline-accent offset-2` | JobDock 的暂停、取消按钮 |
| `ring-2 ring-accent/70` | 人物页卡片、人物详情里的卡片 |
| 文字色半透明描边 | 欢迎页和样片横幅的 `.catalog-action` |
| `ring-2 ring-accent/60` 画在缩略图上、`bg-hover` | 文件夹页的卡片、列表行 |
| 换底色 `bg-accent` | 地图高度拖柄 |
| 去掉焦点环，没有替代 | 侧栏导航行、确认框按钮、图库卡片、视频播放器按钮、详情里的色块、三个排序下拉按钮、文字工具的两个色块按钮 |
| Chromium 默认蓝框 | 其余所有按钮：编辑器工具栏、边框模板网格、拼图、灯箱、设置 |

输入框的写法没问题，保留。按钮的键盘焦点有六种自定义写法，加上 Chromium 默认的蓝框，还有一批被直接去掉了。

### 3.2 按键归谁

`shouldIgnoreKey`（`components/editor/keys.js`）只把输入框、文本域、下拉框和可编辑区当成「正在打字」。焦点在按钮上时，按键既会走 App 的快捷键，也会触发按钮自己的默认动作（空格、回车按下它）。

### 3.3 方向键

- 图库和灯箱：方向键移动选中（`App.jsx` 的 `selectByDirection`），不动焦点。
- 人物页：方向键移动选中，同时把焦点移到新卡片上，为的是盖住旧焦点环。
- 侧栏的合集树、磁盘文件夹树：行本身拿着焦点时，左右键收起和展开，合集行还有 Alt+上下键调整顺序。
- 拼图画布：方向键微移。
- 编辑器：没有绑方向键，模板网格也没有方向键导航。

### 3.4 弹窗

- 十个界面用共用的 `ui/Modal.jsx`（设置、确认框、按清单找图、批量标签、筛选分组、手写字、前后对比等）。它管 Esc 和点背景关闭，不管焦点：打开时不把焦点移进来，Tab 不限制在弹窗里，关闭后焦点也不回到打开前的位置。
- 有输入框的弹窗大多自己 `autoFocus`（TagBatchDialog、FindByListDialog、StickerPickerModal 等）；设置页打开时把焦点拉进来。
- 确认框（`ConfirmDialog.jsx`）没有初始焦点，按钮又去掉了焦点环。用键盘的人看不出焦点在哪。

## 4. 规则

### 规则 1：鼠标给的焦点不留下焦点环，按钮点完交出焦点

`ui/pointerFocus.js`，两个入口（`main.jsx`、`web-main.jsx`）都引入，全 App 一处。

- **按钮这类控件点完交出焦点**：`button`、链接、`summary`、复选框、单选框、滑块（`input[type=range]`）、取色框，以及 `role` 是 tab、switch、checkbox、radio、option、menuitem 的元素。指针按下时浏览器把焦点给了它，松开以后、点击处理完了，焦点还在它身上就 `blur()`，回到 `body`。点 `<label>` 时它的复选框在点击过程中才拿到焦点，按同样的办法处理。
- **其他被指针点到的元素保留焦点，但不画焦点环**：侧栏的合集行和磁盘文件夹行、文件夹页的卡片和列表行（`role="button"` 的 `div`）要在拿着焦点时读方向键（展开、收起、Alt+上下调整顺序），不能交出去。指针按下期间拿到焦点的元素一律标上 `data-pointer-focus`，失去焦点时去掉；`index.css` 不给带这个标记的元素画焦点环。文本框也会被标上，但它们本来就不画焦点环。
- **键盘来的焦点不受影响**：用 Tab 停在按钮上、按回车或空格按下它，焦点都留在原处。
- **排除**：确实要在鼠标点击后保留焦点的按钮加 `data-keep-focus`。目前只有快捷键设置里的录制按钮（它失焦就取消录制）。

为什么在指针松开后、用 `setTimeout` 等点击处理完再 `blur()`，而不是在 `mousedown` 上 `preventDefault` 让焦点根本不动：那样正在编辑的输入框不会失焦，现在靠失焦提交的地方（`InlineEdit` 等）点保存按钮就不提交了，还可能影响拖拽。等点击处理完再交，处理函数里有意把焦点移到输入框或菜单的，焦点在别处，不会被拿掉；也不会在点击中途触发失焦。

做完以后，侧栏导航行、灯箱固定按钮的手写 `blur()` 都删了。人物页按方向键时，只有焦点本来就在网格里（用 Tab 进来的）才跟着移，鼠标点过以后方向键只移选中。

### 规则 2：焦点环只给键盘焦点，全 App 一种样式

- `index.css` 开头一条全局 `:focus-visible` 规则：`--focus-ring` 色、2px、外扩 2px，圆角跟随元素。`--focus-ring` 就是强调色（`--accent-color`），这个 App 的强调色是单色：深色主题下是白，浅色主题下是近黑。
- 规则用 `:where()`，优先级为零：组件上有意写的 `outline-none` 照样生效（录制按钮、模态框的根元素）。
- 文本输入框不在这条规则里，保留各自的聚焦描边。
- 卡片想把焦点环画在缩略图上的，加 `data-focus-ring="first-child"`（文件夹页的卡片）。文件夹页的列表行仍用 `bg-hover` 表示焦点，地图拖柄仍用 `bg-accent`，两处都只在键盘焦点时出现。
- 第 3.1 节里按钮的其他写法都删了，被直接去掉焦点环的也都改用这条统一样式。

### 规则 3：文本输入用完把焦点交回去

点文本框照常拿焦点。回车提交、Esc 取消，两种都把焦点交回 `body`，快捷键回到画布或网格。切图的比例输入框已经这样处理回车。

### 规则 4：网格和列表，方向键移动选中，不移动焦点环

选中用 App 自己的选中样式。图库、灯箱已经是这样，人物页随规则 1 改成了这样。

### 规则 5：弹窗管住焦点

- 打开时焦点进弹窗：有输入框给第一个输入框，没有就给默认按钮；危险操作（删除等）的确认框给「取消」。
- Tab 只在弹窗里循环。
- Esc 关闭（已有）。
- 关闭后把焦点还给打开前的元素。鼠标打开的话那是 `body`，等于不变。

这些都做在 `ui/Modal.jsx` 里，十个界面一起生效。没用 `Modal` 的浮层（StickerPickerModal 等）逐个检查。

## 5. 已拍板（2026-11-26）

1. **焦点环用强调色。** 这个 App 的强调色是单色（深色下白、浅色下近黑），焦点环跟着它。首页和拼图原来的文字色半透明写法一并改掉。
2. **滑块点过不留焦点，跟按钮一样。** 留着虽然能用方向键微调，但编辑器的快捷键不会让开滑块（`shouldIgnoreKey` 对 range 返回 false），两边会抢按键。
3. **边框模板网格先不加方向键。** 以后要加，按规则 4 做成移动选中、直接换模板。

## 6. 落地顺序
