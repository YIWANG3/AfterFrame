AfterFrame 0.5.27 shows a camera's RAW and JPG of one shot as one photo, and gathers the photos whose originals have moved or been deleted in one place to link them again or let them go. It also lets you scale the whole interface. 0.5.26 was never released; everything it had is here too.

The two macOS 12 builds are the same app without People, Scene Depth and Stickers, which use Apple's on-device models that need macOS 14. On an Apple Silicon Mac with macOS 14 or later, take the first one. The Intel build reads RAW files with an older LibRaw (0.21), which can't decode DNGs compressed with JPEG XL.

The Windows installer isn't signed yet. When Windows says "Windows protected your PC" (Windows 已保护你的电脑), click **More info** (更多信息), then **Run anyway** (仍要运行). To update, run the new installer: your catalogs and settings stay. LUTs, Stickers, People and Scene Depth are in the macOS app only for now.

**This version upgrades your catalog.** The first time 0.5.27 opens a catalog it adds a table for RAW+JPG pairs, and 0.5.25 or older can't open that catalog afterwards. A copy of the catalog as it was is left next to it (`catalog.sqlite3.schema14.bak`), should you need to go back.

## New

### A RAW+JPG shot is one photo

A camera set to RAW+JPEG writes two files with one name, and they used to import as two photos, so every shot was picked and rated twice. Now the RAW and the JPG of one shot are one photo.

- **Which files pair:** the same folder, the same name (case doesn't matter), exactly one RAW and one JPG or HEIF of that name there, and capture times within 2 seconds when both have one. Two cameras' `DSC_0001` in different folders stay apart.
- **One photo:** the gallery shows the JPG with a **JPG+RAW** badge, and the Inspector lists the RAW file (click it to show it in Finder). A rating, flag, tags, a description or Remove from Library on the photo apply to both files, and Move to Trash and Copy take both.
- **Your choice, per catalog:** Settings → Library → **Merge RAW+JPG with the same name**. Off, both files show as two photos again, each keeping what it was given while merged; on, they fold back into one. It changes at once, with no re-import. A wrong pair is fixed the same way, as in Lightroom; there is no per-photo split.
- **New catalogs** merge pairs from the start, and the first import that pairs anything says so once, with **Show apart**. **Catalogs you already have** are paired during the upgrade but keep showing two photos as before; the app tells you once that they can be merged (#312, #313, #315).

For agents, MCP `search_assets` records gain `raw_pair_path`, and `has_raw` is true for a merged pair.

### Missing originals in one view

Photos whose originals were moved or deleted in Finder used to show only a **Missing** badge, and could only be relinked one at a time from the Inspector. Now they gather in a view of their own, **Missing Originals**.

- **Ways in:** **View** on the toast that File → Verify Files shows when files are missing, and the **Missing from disk** row on the Statistics page, which can now be clicked.
- **Always current:** opening or refreshing the view checks every file first, so a file you've put back drops out and a newly missing one comes in.
- **Relink All from Folder…** asks for a folder and looks for each original by file name in it and all its subfolders. A file is linked only when its content matches the original, so a different picture with the same name is left alone. The photo keeps its rating, tags and folders, and the toast says how many were relinked, not found, or found with different content.
- **Remove All from Library…** asks first and says that ratings, tags and folder memberships go with the photos. Nothing on disk is touched.
- With two or more photos selected, both act on the selection only ("Relink 2 from Folder…") (#311).

For agents, MCP `search_assets` takes `status: "missing"`, and `maintain_library` gains `relink_from_folder`.

### Interface scale

- **Settings → General → Interface scale** scales the whole window to 80, 90, 100, 110 or 125 %. It takes effect at once and stays after a restart. The default is still 100 %, so nothing changes until you pick a scale.
- **View → Zoom In / Zoom Out / Actual Size** on ⌘= / ⌘- / ⌘0 (Ctrl+= / Ctrl+- / Ctrl+0 on Windows) step one notch up or down, or go back to 100 %. The number pad's + / - / 0 work too, and you can rebind all three in Settings → Shortcuts. The thumbnail-size keys stay plain `=` and `-` (#309).

The scale isn't part of a settings backup yet.

## Changed

### The Similar strip shows only the same scene

The **Similar** strip in the Inspector (and in the lightbox's details pane) used to show the eight nearest photos however far off they were. A photo with no real look-alike got eight photos of the same kind of subject from other days. It now lists only photos of the same scene: another frame of a burst, the same spot recomposed, another crop or edit of the picture. So it often shows fewer than eight, and for a photo with nothing close it isn't shown at all.

**Find Similar** (the full gallery view) and the MCP `find_similar` tool are unchanged and still give the full ranked list. No re-indexing needed (#308).

## Fixed

- **A switch that is on can be seen in the dark theme.** Its knob was white on a white track; it is now dark on it (#314).
- **The lightbox's details pane is readable over a photo.** It has a dark, blurred ground of its own instead of a nearly transparent one, and the seam that showed on the photo at the pane's left edge is gone (#307).
- **The tag picker stays open when a short window puts Add tag at the bottom edge.** Adding a photo's first tag of a group pushed the input out of view and the picker closed itself. It now scrolls the input back into view (#308).
