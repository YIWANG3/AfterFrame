This release is about large RAW libraries: importing a whole drive, reading every camera's files, and staying usable while that runs.

## Highlights

### RAW files read with LibRaw

AfterFrame now reads RAW files with [LibRaw](https://www.libraw.org/), which supports more than 1,200 cameras.

- **HD previews on demand:** importing RAW files no longer renders a full-size HD preview of each one. It is made the first time you open the photo in the lightbox, editor or collage.
- **Previews from the camera:** when the camera's embedded preview is big enough, AfterFrame uses it instead of rendering the RAW.
- **Files macOS can't render:** when the system's decoder fails or returns a black image, AfterFrame decodes the RAW with LibRaw.
- **One bad file can't stall previews:** every render has a time limit, and LibRaw runs in its own process, so a file that can't be read costs only its own preview.
- **Adobe RGB:** photos shot in Adobe RGB get Adobe RGB previews.

### Metadata read with ExifTool

Camera data now comes from [ExifTool](https://exiftool.org/).

- **CR3:** ISO, shutter speed, aperture, focal length, lens and colour space now show for Canon CR3 files. Before, they were blank.
- **IIQ and some NEF and DNG files:** camera, date and exposure are read even when they sit deep in the file.
- **Lenses:** older Nikon lenses show by name. Placeholders like `----` no longer show as a lens.
- **Adobe RGB** is detected for Nikon and Fujifilm, which record it outside the usual EXIF field.
- **Photos you already imported** keep what was read before. To read them again, select them, right-click and choose **Refresh from Disk**.

### Capture times match the camera's clock

- **The fix:** capture times were shifted by your time zone. A photo taken at 18:05 in China showed at 02:05 the next day.
- **Saved copies:** editing a photo wrote that shifted time into the saved copy. Now it keeps the camera's time.
- **Catalog upgrade:** 0.5.8 fixes the stored times the first time it opens a catalog. After that, 0.5.7 can't open that catalog.

### Big imports

These come from importing a 2 TB drive of RAW files ([#130](https://github.com/YIWANG3/AfterFrame/issues/130)).

- **Photos appear while the import runs,** a batch at a time with their thumbnails. Before, the library stayed empty until the whole import finished, which took hours on a large drive.
- **Watched drives:** watching an imported folder no longer opens one file handle per photo. On a big drive the app ran out of handles: the gallery went empty and "spawn … EMFILE" errors kept appearing, on every launch.
- **All Assets count:** it now includes RAW files and videos imported as photos. Before, it counted only the JPEGs.
- **Add RAW Sources on an imported folder:** it no longer fails with `UNIQUE constraint failed`.

### Quieter when idle

The gallery used 35–40% CPU while it sat there, because a loading animation kept running under thumbnails that had already loaded. It now uses about 2.5%.

### Also in this release

- **Edits can join their folder:** Save, Split and AI Repaint opened from a folder can add the result to that folder, as the collage already could. The editor and the collage share one setting for this, on by default.
- **Larger download:** the DMG is about 6 MB bigger, for ExifTool and LibRaw.
