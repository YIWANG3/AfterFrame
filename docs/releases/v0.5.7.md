0.5.6 was never published, so this is the first release since 0.5.5. It includes everything added since then.

## Highlights

### People recognition works out of the box

The face model is now part of the app, so there is nothing to download before scanning faces.

- **Why:** in 0.5.5 it was a 110 MB download from Hugging Face the first time you used People. That failed for many users in mainland China, and when the connection stalled, the button kept spinning with no error.
- **Existing people stay grouped:** it is the same model 0.5.5 downloaded. That copy is removed to free about 125 MB.
- **Needs macOS 14 or later.** On macOS 12 and 13, People says so instead of failing during a scan.
- **Larger download:** the DMG is about 110 MB bigger.

### Exports keep their camera data

Photos saved from the editor keep the original's EXIF in the released app: camera, lens, exposure, date and GPS. This covers saves with a frame, text, a collage or a split. Release builds of 0.5.5 dropped it.

### Runs on macOS 12–15 without Xcode

- **Older macOS:** in 0.5.5 the helpers behind video posters, playback proxies and people recognition needed macOS 26. Now video posters and playback proxies work from macOS 13, and people recognition from macOS 14.
- **No developer tools:** depth-aware text and sticker subject detection no longer need Xcode or the Command Line Tools.
- **Faster depth:** scene depth for a new photo takes about 0.2 s instead of about 16 s, because the compiled model is kept between runs.

### Faster previews

- **JPEG, PNG, HEIC, TIFF, WebP and AVIF:** AfterFrame now renders thumbnails and HD previews itself, about three times faster per photo. Orientation and colour profiles are carried over as before.
- **CMYK (print exports):** previews go through the image's own colour profile and show its real colours.
- **RAW and video:** previews are unchanged.

### Import fixes

- **Dock drops:** photos dropped on the Dock icon while AfterFrame isn't running are imported once it opens. Before, they were lost.
- **Whole cards and drives:** importing one skips its trash and system folders (`.Trashes`, `.Spotlight-V100`, Windows' `$RECYCLE.BIN`), so deleted photos don't come back as imports.

### Smaller things

- The logo is the app icon's rounded square everywhere.
- With the interface in Chinese, the app declares its language, so text uses Chinese glyph forms.
- On a small screen, the window opens within the screen instead of past its edge.
- Errors in Settings → People appear next to the button that caused them, not at the bottom of the page.

## Groundwork for Windows

This release carries most of the work toward a Windows version: window controls, file paths, previews, HEIC, RAW previews, single instance and Windows wording. On macOS it changes nothing beyond the items above. There is no Windows download yet.
