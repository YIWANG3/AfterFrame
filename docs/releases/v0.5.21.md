AfterFrame 0.5.21 is a small follow-up to 0.5.20: the Folders page takes a folder dragged in from Finder, as the sidebar does, and the sidebar's folders line up with the smart collections above them.

## Download

| | File | Needs |
|---|---|---|
| **Mac, Apple Silicon** | `AfterFrame-0.5.21-arm64.dmg` | macOS 14 or later |
| **Mac, Apple Silicon, older macOS** | `AfterFrame-0.5.21-macOS12-arm64.dmg` | macOS 12 or 13 |
| **Mac, Intel** | `AfterFrame-0.5.21-macOS12-Intel.dmg` | macOS 12 or later |
| **Windows** | `AfterFrame-0.5.21-x64-setup.exe` | Windows 10 or 11, 64-bit |

The two macOS 12 builds are the same app without People, Scene Depth and Stickers, which use Apple's on-device models that need macOS 14. On an Apple Silicon Mac with macOS 14 or later, take the first one. The Intel build reads RAW files with an older LibRaw (0.21), which can't decode DNGs compressed with JPEG XL.

The Windows installer isn't signed yet. When Windows says "Windows protected your PC" (Windows 已保护你的电脑), click **More info** (更多信息), then **Run anyway** (仍要运行). To update, run the new installer: your catalogs and settings stay. LUTs, Stickers, People and Scene Depth are in the macOS app only for now.

A catalog opened by 0.5.19 or later can't be opened by 0.5.18 or older (the folder tree and tag groups added in 0.5.19). 0.5.21 doesn't change the catalog format.

## New

### Drop a folder on the Folders page

0.5.20 made the sidebar take a folder dragged in from Finder and turn it into a folder of the library. The Folders page shows the same folders and took nothing. Now it does.

- **On the page**, the folder is imported and becomes a top-level folder of that name.
- **On a folder's card**, or its row in the list view, it becomes a subfolder of that folder. Loose files dropped there are imported and added to that folder.
- While you drag, what would take the drop is outlined: the page, the card or the row.

The rules are the sidebar's: dropping the same folder again makes neither a second folder nor second copies, and when one folder was made it opens.

## Changed

### A tidier sidebar

- **Folders line up with the smart collections.** A single nested folder used to push every folder to the right, to keep a column for the open and close arrow. The arrow now sits at the right end of the row, after the count, and only on a folder that has folders inside. Subfolders still indent.
- **A row's actions are in its right-click menu.** For a folder: New subfolder, Annotate, Rename and Delete. For a smart collection: Edit conditions, Copy current photos to a folder, Rename and Delete. The small buttons that appeared on hover are gone, so hovering a row no longer cuts its name short.
