# AfterFrame 0.4.7 - Overlay Masks & Collage Fixes

Patch release covering the refinements since v0.4.6.

## Highlights

### One overlay layer, everywhere

- The wash a frame preset ships with is now the same overlay (蒙层) layer you add yourself: both get paint (solid or gradient) **and** coverage — which edge the wash grows from (bottom / top / left / right) and how far it reaches.
- Gradients support multiple stops, Figma/Sketch style: click the bar to add a stop, drag to move it, `−` or Delete to remove, set its position in %, reverse. Available on overlay layers and the canvas background.
- Live preview and export share one geometry/color path, so what you see is what gets saved.

### Frame presets scale consistently across aspect ratios

- Logo, text and margins are now sized from the photo's short edge (calibrated so 3:2 frames are unchanged). Portrait and panoramic photos get the same visual weight of branding — previously a 16:9/pano logo rendered about twice as large as on a 4:5.

### Collage

- Fixed blurry cells in exported collages: photos that had appeared in an earlier collage session could stay on the 512px thumbnail instead of picking up their 2000px preview. The export now also logs when a cell falls back to a lower-resolution source.

## Verification

- Renderer unit tests (61) and the editor / frame / canvas-pad / save / collage e2e suites (51) pass, including new cases for overlay coverage and multi-stop gradients.
