AfterFrame 0.5.18 adds two small things for sorting and arranging: a target folder you fill with one key, and a Shuffle button in the collage maker. Nothing else changes.

## Download

| | File | Needs |
|---|---|---|
| **Mac, Apple Silicon** | `AfterFrame-0.5.18-arm64.dmg` | macOS 14 or later |
| **Mac, Apple Silicon, older macOS** | `AfterFrame-0.5.18-macOS12-arm64.dmg` | macOS 12 or 13 |
| **Mac, Intel** | `AfterFrame-0.5.18-macOS12-Intel.dmg` | macOS 12 or later |
| **Windows** | `AfterFrame-0.5.18-x64-setup.exe` | Windows 10 or 11, 64-bit |

The two macOS 12 builds are the same app without People, Scene Depth and Stickers, which use Apple's on-device models that need macOS 14. On an Apple Silicon Mac with macOS 14 or later, take the first one. The Intel build reads RAW files with an older LibRaw (0.21), which can't decode DNGs compressed with JPEG XL.

The Windows installer isn't signed yet. When Windows says "Windows protected your PC" (Windows 已保护你的电脑), click **More info** (更多信息), then **Run anyway** (仍要运行). To update, run the new installer: your catalogs and settings stay. LUTs, Stickers, People and Scene Depth are in the macOS app only for now.

A catalog opened by 0.5.13 or later can't be opened by 0.5.12 or older (the look-alike index added in 0.5.13). 0.5.18 doesn't change the catalog format.

## New

### A target folder, filled with one key

Sorting a shoot into a new folder meant dragging every photo to the sidebar, or going through the context menu's folder list each time. Now the folder you last made, or last added photos to by any means, is the **target folder**, and **B** adds the selected photos to it: a grid selection, or the photo open in the lightbox. **Shift+B** adds the one photo and moves on to the next, like Shift+P and Shift+X do for flags.

- The sidebar marks the target folder with a small `B`. The context menu's **Add to Folder** list leads with it.
- The target is remembered per catalog, so it survives a restart, and is dropped when the folder is deleted. Without one, B says how to get one.
- **Settings → Keyboard Shortcuts** lists the action as **Add to Target Folder** under Organize, rebindable like the rest.

### Shuffle the collage

The collage maker's Images section has a **Shuffle** button from two photos up, in both single and batch mode. One click deals the photos into a new arrangement, never the one you already had. In batch mode the pages keep their size and count; only which photo lands where changes, and each photo's pan and zoom follows it. The new order counts as your manual order, so a sort you pick afterwards wins and the next shuffle starts from there.

## Under the hood

- **CI fetches Electron once and keeps it.** The test jobs used to pull the Electron binary from GitHub's release CDN on every run, and a day of 504s there failed every suite. They now fetch it once with retries, fall back to GitHub's API when the release link fails, and cache it between runs. No change to the app.
