AfterFrame 0.5.16 imports the formats photographers actually shoot (HEIF stills from Canon, Sony and Fujifilm, PSD, GIF, BMP, AVCHD, 3GP), shows and edits TIFFs, reads the stars Lightroom writes in an XMP sidecar, and lets the AI repaint take its colours from photos you pick. It also puts the lightbox, editor and collage headers back where 0.5.13 had let the Mac's traffic lights cover them, and gives every field in the app one look. It is the update after 0.5.13: 0.5.14 and 0.5.15 were never released.

| **Windows** | `AfterFrame-0.5.16-x64-setup.exe` | Windows 10 or 11, 64-bit |

The two macOS 12 builds are the same app without People, Scene Depth and Stickers, which use Apple's on-device models that need macOS 14. On an Apple Silicon Mac with macOS 14 or later, take the first one. The Intel build reads RAW files with an older LibRaw (0.21), which can't decode DNGs compressed with JPEG XL.

The Windows installer isn't signed yet. When Windows says "Windows protected your PC" (Windows 已保护你的电脑), click **More info** (更多信息), then **Run anyway** (仍要运行). To update, run the new installer: your catalogs and settings stay. LUTs, Stickers, People and Scene Depth are in the macOS app only for now.

A catalog opened by 0.5.13 or later can't be opened by 0.5.12 or older (the look-alike index added in 0.5.13). 0.5.16 doesn't change the catalog format.

## Highlights

### More formats import

| Family | Extensions | Shown as |
|---|---|---|
| HEIF stills | `.heif` `.hif` (Canon R, Sony, Fujifilm), next to `.heic` | rendered on demand, as HEIC already was |
| Photoshop | `.psd` (the flattened composite; `.psb` isn't read) | rendered on demand |
| GIF, BMP | `.gif` (first frame) `.bmp` | as they are |
| JPEG aliases | `.jfif` `.jpe` `.insp` (Insta360) | as JPEG |
| AVCHD | `.mts` `.m2ts` | the original clip on the Mac; an H.264 proxy on Windows, as for HEVC |
| 3GP | `.3gp` | as it is |

**The full list lives in Settings → Library → Supported formats** (设置 → 图库 → 支持的格式), by kind: Photos, RAW, Video. It is generated from the one table the app imports by, so it can't go stale.

**An import says what it skipped.** Files outside that list used to be dropped without a word. Now the import's toast counts them by type ("Skipped 3 unsupported files: DOCX ×2 · ZIP ×1") with a button to the formats list; sidecars and companions (`.xmp`, `.thm`, `.lrv`, `.aae`…) are counted but not nagged about. A lone file dropped on the window only becomes a library root when it is something the catalog imports, so a stray `.docx` no longer sits in the roots list.

**TIFF shows its own pixels and opens in the editor.** The lightbox used to fall back to the HD preview for a `.tif`, and the editor couldn't open one at all. A TIFF is now rendered on demand like HEIC: a near-lossless JPEG (quality 95) that keeps the colour profile and EXIF, which 16-bit and CMYK scans go through too. Those renders live in a bounded cache under the app's data folder (the most recently used 1 GiB, listed as **Rendered originals** in Settings → Library → Cache & storage) instead of the system temp folder, which Windows never empties; the old temp folder is cleaned up on first launch.

**The Format filter lists families, not extensions.** JPG and JPEG were two choices, HEIC / HEIF / HIF three, and a Canon RAW said "cr3". The filter bar's Format facet now shows one JPEG, one HEIF, TIFF, "Canon CR3" and so on, and picking a family finds every file in it whatever its extension. A smart collection saved with a single extension still means exactly that extension.

### Lightroom's stars come along

Lightroom Classic, Bridge and Camera Raw rate a RAW in an XMP sidecar beside it (`IMG.xmp`; darktable writes `IMG.CR2.xmp`), and the RAW itself never changes, so a Lightroom-rated library used to arrive unrated. Import now reads the sidecar's `xmp:Rating`, which beats the one embedded in the file. The rule for both is the same: **the app follows the file's stars until you rate the photo here**, including when Lightroom re-rates or clears them; a rating set or cleared in AfterFrame stays. In a watched folder, a sidecar that appears, changes or goes counts as that photo changing, without remaking its previews.

### The AI repaint takes its colours from photos you pick

The AI Repaint panel gains **Reference images**: pick one to four photos, and the repaint matches their palette, tones and mood while keeping this photo's content, for colour-matching another photographer's look or your own earlier edit. Agents get the same through the MCP `repaint_asset` tool (`reference_asset_ids` for catalog photos, `reference_paths` for files).

- **Uploads are smaller.** References travel as JPEGs no longer than 1536 px, and a heavy export (a 7 MB camera JPEG, say) is re-encoded before it goes up, which used to stall Seedream's upload.
- **Versions show a thumbnail**, so the Results and Versions lists say what each repaint looks like.
- **The reference picker remembers its folder**, for repaint and handwriting alike.

### The headers make room for the traffic lights again

In 0.5.13 on the Mac, the close, minimise and zoom buttons sat on top of the lightbox title, the editor's file name and the collage's Single / Batch switch, and the editor and collage titles were no longer centred. The lightbox header has its left gutter back, the editor and collage headers are 44 px high with the title centred, and all three can be dragged to move the window again. The collage's flat borders and pill switch are back too.

### One look for every field

Every text field, number field, dropdown, slider and text area in the editor panels, the dialogs, the filter bar and Settings now shares one set of sizes and corners: 24 px fields with 6 px corners, 28 and 32 px fields with 8 px, no border, a filled background and a ring on focus. Before, the same control could come out at any of five radii depending on where it sat.

**Number fields keep what you type.** A value inside the range applies as you type; a value outside it, or a half-typed one, waits for Enter or for the field to lose focus, then clamps. Fields that scrub still scrub.

### Also in this release

- **A search typed while the gallery jumps to a photo is kept.** After you click one of a photo's versions (版本), or choose **Show in All Assets** (在全部素材中定位), a search typed before the photo showed used to be replaced when the jump landed.
- **Short AVCHD clips get a poster on Windows.** FFmpeg found no frame when its seek went past a one-second MPEG-TS clip's only keyframe; it now takes the first frame instead. The Mac's AVFoundation path was never affected.
- **One table decides what imports.** The sidecar, the watcher, the lightbox, the Dock's file types and the export dialogs used to keep their own copies of the format list, and they disagreed (the watcher accepted GIFs the import then dropped, and missed eight RAW types). They now all read one registry, with a test that fails when any copy drifts.
