# AfterFrame 0.2.0 — Agent-Native

AfterFrame can now be driven by AI agents. An embedded MCP server lets Claude Code (or any MCP-compatible agent) control your library in natural language while the app runs — search, import, crop, tag, export, and more, with everything visible and cancellable in the app.

## ✨ New

### Agent-Native (MCP)
- **Embedded MCP server** on `127.0.0.1:41706` with **17 tools**: catalog overview, faceted search with agent-viewable thumbnails, asset detail, import, non-destructive crop into version stacks, batch export (resize/transcode), tags & ratings, collections, AI annotation & repaint jobs, deletion, and job control
- **Two-way selection bridge** — select photos in the app and tell the agent "these"; the agent's picks are highlighted and scrolled into view in your gallery
- **Agent work is visible** — agent-started jobs appear in the background-activity dock with live progress and a Cancel button; agent edits refresh the UI instantly with a toast
- **Zero config** — the repo ships `.mcp.json`; Claude Code connects automatically. Local-only, BYOK privacy unchanged
- Domain instructions are served to every connecting agent, so it understands assets, version stacks, collections, and jobs out of the box

### Editing & Export (also available to agents)
- **Non-destructive crop to aspect ratio** (`create-derived`) — results join the original's version stack, EXIF preserved
- **Batch export** with max-edge resize and JPEG/PNG/WebP transcode, EXIF preserved
- **Settings → AI Repaint** — manage repaint providers and per-provider default models globally (the agent uses the same defaults)

## ⚡️ Performance
- Resident sidecar process: catalog operations drop from ~160ms to ~5–8ms per call
- New SQLite indexes for the hottest browse queries
- Gallery cards are memoized; background polling no longer re-renders the whole app every 1.2s
- Background refreshes keep your scroll position and selection (no more jump-to-top)
- Annotations ship inline with browse results — the inspector renders them instantly, no flicker

## 🔒 Security
- `media://` file access tightened from "any file on disk" to a strict allowlist (catalog, registered roots, app data)
- API keys no longer appear in process arguments or logs (env-based handoff)
- MCP endpoint hardened: Host/Origin guards, request size caps, export destination constraints

## 🐛 Fixes
- AI Repaint results now appear in the grid without a manual refresh
- Preview-HD generation no longer chains after a failed preview pass
- Collection → status filter switching no longer mixes datasets
- Depth fields, rotated saves, and catalogs under symlinked paths (e.g. /tmp) load correctly
- JobDock/toast visual cleanup (no more heavy outlines); toolbar collapses gracefully on narrow windows

## 🧪 Internals
- Test suite: 43 e2e (incl. full MCP/agent-bridge coverage) + 40 unit, all green
- Major refactors landed: UI primitives layer, API facade, shared sidecar command layer, CLI dispatch registry
