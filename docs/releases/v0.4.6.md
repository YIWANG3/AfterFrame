# AfterFrame 0.4.6 - Editor Polish

Patch release covering the refinements since v0.4.5.

## Highlights

### Text, stickers, and overlays

- Added outer glow controls for both text and sticker layers, making titles and cutouts easier to read over detailed photos.
- Added independent opacity control for sticker outlines.
- Fixed overlay-layer stacking in the live editor preview so it matches Apply and export.

### AI handwriting showcase

- Updated the project site and bilingual READMEs with a four-scene gallery made in AfterFrame.
- Added finished-image acceptance criteria for natural strokes, clean matting, recoloring, multi-line layout, and readability over complex photography.

### Collage and provider polish

- Photos already used in a collage now remain visible in the source picker with a subdued state instead of disappearing.
- Fixed a duplicated namespace in collage source-filter translations.
- Deduplicated cached provider model lists, including Volcengine Ark snapshots.

## Verification

- Repository quality checks pass.
- The updated handwriting showcase was checked at desktop and mobile viewport sizes with no browser errors.
