FFmpeg — third-party licenses
=============================

On Windows the sidecar makes video posters, durations, the hover filmstrip
and the H.264 playback proxy with FFmpeg, run as separate programs
(Resources/native/ffmpeg: ffmpeg.exe and ffprobe.exe with FFmpeg's shared
libraries, avcodec and the others, which can be replaced with compatible
builds). The macOS app doesn't ship it: it uses AVFoundation.

The libraries built into it are under licenses compatible with the LGPL.
Among those the app relies on: dav1d (BSD-2-Clause), OpenH264
(BSD-2-Clause), zimg (WTFPL) and zlib (zlib). The H.264 proxy is encoded
with Windows' own Media Foundation encoder where Windows has one.
