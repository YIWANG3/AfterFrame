ExifTool — third-party license
==============================

The sidecar reads photo metadata (camera, lens, exposure, capture time, GPS,
rating) with ExifTool, run as a separate program
(Resources/native/exiftool).

  AfterFrame ships its program unmodified. The macOS copy is the script and
  its modules (exiftool, lib/, README) without the .pod manuals; the HTML
  documentation, the test suite and the build files are left out. It runs
  with the system's /usr/bin/perl.

Windows: ExifTool for Windows, packaged by Oliver Betz
  https://oliverbetz.de/pages/Artikel/ExifTool-for-Windows
  It brings Strawberry Perl 5.32 (Artistic / GPL) and the MinGW runtime
  (libgcc_s, libstdc++: GPL-3.0 with the GCC Runtime Library Exception;
  libwinpthread; liblzma). Its license texts ship beside it, in
  native/exiftool/exiftool_files (LICENSE, Licenses_Strawberry_Perl.zip).
