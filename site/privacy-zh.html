AfterFrame / 隐私

你的照片，
始终由你掌控。

AfterFrame 是一款本地优先的桌面应用。无需注册账号，不包含遥测，也不会收集你的照片库或个人数据。

生效日期：2026 年 7 月 12 日本地优先无需账号

01 / 适用范围

本政策适用于什么。

本政策适用于 AfterFrame macOS 应用及 AfterFrame 项目官网。AfterFrame 是用于整理和编辑本机媒体文件的开源软件。

02 / 本地数据

图库保留在你的设备上。

照片、视频、预览、Catalog 记录、元数据、评分、标签、人脸特征和人物组均保存在你的 Mac 或你选择的 Catalog 位置。AfterFrame 不会把你的图库上传至 AfterFrame 服务器。

03 / 数据收集

无账号，无遥测。

AfterFrame 应用没有账号系统、分析工具、遥测、广告 SDK 或内置崩溃上报服务。AfterFrame 项目不会为了广告或用户画像收集、出售、出租或共享你的个人数据。

04 / 可选 AI 服务

是否使用外部 AI，由你决定。

AI 重绘和 AI 自动标注是可选的自带密钥功能。只有当你配置服务商并主动启动其中一项功能时，AfterFrame 才会从你的设备把所选照片内容和请求直接发送至你选择的服务商。这是照片内容通过 AfterFrame 离开设备的唯一情形。

AfterFrame 不会接收这些照片或请求。所选服务商会按照其自身条款和隐私政策处理数据，请在使用前阅读相关政策。API 凭据由你提供，不会发送给 AfterFrame 项目。

05 / 本地 MCP

Agent 桥接服务留在本机。

AfterFrame 的 MCP 服务在你的电脑上运行，并监听本地回环地址 127.0.0.1。AfterFrame 不会将该服务暴露到公网。你连接的 MCP 客户端可能有其自身的隐私政策。

06 / 网站托管

由 GitHub Pages 托管的静态网站。

AfterFrame 官网没有添加分析工具、追踪像素、广告 Cookie、账号表单或其他数据收集脚本。网站托管于 GitHub Pages。GitHub 表示，访客 IP 地址会出于安全目的被记录和保存，并可能依据其 隐私声明处理其他基础服务使用信息。

网站通过 Google Fonts 加载字体。浏览器获取字体文件时，可能会向 Google 发送 IP 地址、User Agent 等基础请求信息；相关处理适用 Google 的 隐私政策。

07 / 政策更新

本政策的变更。

如果 AfterFrame 的数据处理方式发生变化，我们会更新本页面及上方生效日期。重大变化也会记录在公开项目仓库中。

08 / 联系方式

隐私问题与请求。

如对本政策或 AfterFrame 的隐私实践有疑问，请在公开 GitHub 仓库中提交 Issue。请勿在公开 Issue 中包含敏感个人信息。
