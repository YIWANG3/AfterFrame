01 / 开始使用

安装后，选一个文件夹。

从 GitHub Releases 下载最新 DMG，移至“应用程序”后打开。第一次使用时创建目录；它只索引照片，不会接管你的文件。

下载最新版本 ↓
macOS 提示若 macOS 阻止未公证的构建，请按住 Control 点按应用并选择“打开”，或在隐私与安全性中允许打开。

02 / 建立图库

导入你已经拥有的照片。

使用“导入”选择包含照片或视频的文件夹。预览和元数据会在后台生成，你可以马上开始浏览。

  1. 创建或打开一个目录。
  2. 选择一个拍摄文件夹。
  3. 在活动 Dock 中等待预览和元数据完成。
  4. 排序、评分、打标、建立收藏。

03 / 编辑

在挑选照片的地方，完成编辑。

裁切、添加文字、制作拼贴、添加贴纸或相机相框。原片不会被改动，按需要的尺寸导出即可。

  • 裁切：预设比例、旋转和翻转。
  • 文字：系统字体、渐变、阴影与深度感知位置。
  • 相框：EXIF 感知的相机样式与品牌标识。

04 / 使用自己的 AI

使用你信任的服务商。

在“设置”中使用自己的 API Key 配置 AI 重绘和 AI 自动标注。请求会直接从你的设备发往所选择的服务商。

AI 重绘用提示词或内置风格转换图片。
AI 自动标注生成标题、标签、识别文字和位置猜测。
兼容服务商Gemini、GPT Image、Anthropic、即梦及兼容端点。

05 / 连接 Agent

让 Agent 和你的图库一起工作。

应用运行期间，AfterFrame 会启动本地 MCP 服务。将它添加到兼容 MCP 的客户端后，即可搜索、打标、裁切、导出，或在应用中展示照片。

Claude Code

claude mcp add --transport http afterframe http://127.0.0.1:41706/mcp

Codex CLI

codex mcp add afterframe --url http://127.0.0.1:41706/mcp

服务只监听 127.0.0.1；Agent 任务会显示在活动 Dock 中，也可随时取消。
