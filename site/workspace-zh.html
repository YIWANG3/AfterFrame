本地优先的照片工作台

所有照片，
都在一处。

把不同文件夹和硬盘里的照片放进同一个目录中浏览、筛选、评分、打标签和建立收藏。原片仍留在原来的位置。

张图片依然流畅
本地
文件仍在原处
检索
标签与参数都能查找

目录管理 · 搜索与筛选 · 评分与标签 · 智能收藏 · 本地 MCP

01 / 图库

筛选、评分，
找到要留的。

按相机、镜头、标签、格式、曝光参数、日期和评分组合筛选，同时查看完整元数据。

如何管理图库 →

02 / 文字与相框

文字可以放在
主体后面。

添加文字、描边和相框，并用本地深度模型把文字放到画面主体后方。

查看编辑工具 →

03 / 拼图

把一组照片，
排成一张。

选择布局，逐格缩放和平移，调整间距、留白、圆角与背景后高分辨率导出。

04 / AI 重绘

保留原图，
尝试另一种画面。

使用你自己的 AI 服务和 API Key 重绘照片，并在同一画面比较原图与结果。

配置 AI 服务 →

05 / MCP

想找哪张，
直接问图库。

通过本地 MCP，让 Agent 搜索、打标、裁切、导出并在应用中展示选择。

claude mcp add --transport http afterframe http://127.0.0.1:41706/mcp
